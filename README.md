# DeepPaperNote-Explainer

A teaching-oriented enhancement overlay for the upstream DeepPaperNote skill.

This package deliberately does **not** vendor upstream scripts. It preserves the upstream deterministic pipeline and adds a mechanism-teaching layer for formulas, algorithms, module interactions, experiments, and critical analysis.
